Browse and manage profiles

USAGE
  openshell profile [OPTIONS] [COMMAND]

COMMANDS
  list      List available profiles
  describe  Describe a profile's credentials, endpoints, and policy defaults
  export    Export a provider profile
  import    Import provider profiles from a file, directory, or HTTP URL
  update    Update an existing custom provider profile from a file
  lint      Validate provider profile files without registering them
  delete    Delete a custom provider profile

FLAGS
  -g, --gateway <GATEWAY>
          Gateway name to operate on (resolved from stored metadata)
          
          [env: OPENSHELL_GATEWAY=]

      --gateway-endpoint <GATEWAY_ENDPOINT>
          Gateway endpoint URL (e.g. <https://gateway.example.com>). Connects directly without looking up gateway metadata
          
          [env: OPENSHELL_GATEWAY_ENDPOINT=]

      --gateway-insecure
          Skip TLS certificate verification for gateway connections
          
          [env: OPENSHELL_GATEWAY_INSECURE=]

      --workspace <WORKSPACE>
          Workspace scope for resource operations
          
          [env: OPENSHELL_WORKSPACE=]
          [default: default]

  -v, --verbose...
          Increase verbosity (-v, -vv, -vvv)

      --color <WHEN>
          When to colorize output. `auto` colorizes only when stdout is a terminal

          Possible values:
          - auto:   Colorize a stream only when that stream is a terminal and no environment override applies
          - always: Always colorize, even when output is redirected
          - never:  Never colorize
          
          [env: OPENSHELL_COLOR=]
          [default: auto]

  -h, --help
          Print help

  -V, --version
          Print version


EXAMPLES
  $ openshell profile list
  $ openshell profile list --type provider -o json
  $ openshell profile describe openai
  $ openshell profile export openai
  $ openshell profile import -f custom-api.yaml
