Manage sandbox services

USAGE
  openshell service [OPTIONS] [COMMAND]

COMMANDS
  expose  Expose an HTTP service running inside a sandbox
  list    List exposed sandbox service endpoints
  get     Show one exposed sandbox service endpoint
  delete  Delete one exposed sandbox service endpoint

FLAGS
  -g, --gateway <GATEWAY>
          Gateway name to operate on (resolved from stored metadata)
          
          [env: OPENSHELL_GATEWAY=]

      --gateway-endpoint <GATEWAY_ENDPOINT>
          Gateway endpoint URL (e.g. <https://gateway.example.com>). Connects directly without looking up gateway metadata
          
          [env: OPENSHELL_GATEWAY_ENDPOINT=]

      --gateway-insecure
          Skip TLS certificate verification for gateway connections
          
          [env: OPENSHELL_GATEWAY_INSECURE=]

      --workspace <WORKSPACE>
          Workspace scope for resource operations
          
          [env: OPENSHELL_WORKSPACE=]
          [default: default]

  -v, --verbose...
          Increase verbosity (-v, -vv, -vvv)

      --color <WHEN>
          When to colorize output. `auto` colorizes only when stdout is a terminal

          Possible values:
          - auto:   Colorize a stream only when that stream is a terminal and no environment override applies
          - always: Always colorize, even when output is redirected
          - never:  Never colorize
          
          [env: OPENSHELL_COLOR=]
          [default: auto]

  -h, --help
          Print help

  -V, --version
          Print version


ALIAS
  svc

EXAMPLES
  $ openshell service expose my-sandbox 8080
  $ openshell service expose my-sandbox 8080 web
  $ openshell service list
  $ openshell service list my-sandbox
  $ openshell service get my-sandbox web
  $ openshell service delete my-sandbox web
