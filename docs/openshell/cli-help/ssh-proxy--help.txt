SSH proxy (used by `ProxyCommand`).

Two mutually exclusive modes:

**Token mode** (used internally by `sandbox connect`): `openshell ssh-proxy --gateway <url> --sandbox <name> --token <token>`

**Name mode** (for use in `~/.ssh/config`): `openshell ssh-proxy --gateway <name> --name <sandbox-name>`

USAGE
  openshell ssh-proxy [OPTIONS]

FLAGS:
  -g, --gateway <GATEWAY>
          Gateway URL (e.g., <https://gw.example.com:443/proxy/connect>). Required in token mode. In name mode, can be a gateway name

      --sandbox <SANDBOX>
          Sandbox name. Required in token mode

      --token <TOKEN>
          SSH session token. Required in token mode

      --server <SERVER>
          Gateway endpoint URL. Used in name mode. Deprecated: prefer --gateway

      --gateway-name <GATEWAY_NAME>
          Gateway name. Used with --name to resolve gateway from metadata

      --name <NAME>
          Sandbox name. Used in name mode

GATEWAY FLAGS:
      --gateway-endpoint <GATEWAY_ENDPOINT>
          Gateway endpoint URL (e.g. <https://gateway.example.com>). Connects directly without looking up gateway metadata
          
          [env: OPENSHELL_GATEWAY_ENDPOINT=]

      --gateway-insecure
          Skip TLS certificate verification for gateway connections
          
          [env: OPENSHELL_GATEWAY_INSECURE=]

GLOBAL FLAGS:
      --workspace <WORKSPACE>
          Workspace scope for resource operations
          
          [env: OPENSHELL_WORKSPACE=]
          [default: default]

  -v, --verbose...
          Increase verbosity (-v, -vv, -vvv)

      --color <WHEN>
          When to colorize output. `auto` colorizes only when stdout is a terminal

          Possible values:
          - auto:   Colorize a stream only when that stream is a terminal and no environment override applies
          - always: Always colorize, even when output is redirected
          - never:  Never colorize
          
          [env: OPENSHELL_COLOR=]
          [default: auto]

  -h, --help
          Print help

  -V, --version
          Print version
