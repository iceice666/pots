# OAuth 登入遷移

這是 **GPUI 所見即所得編輯器**的輸入法測試文件。修改只留在記憶體中，關閉視窗後不會保存。

## 中文輸入法測試

- [ ] 在這一行後面用注音或倉頡輸入「登入流程」，選字視窗應該出現在游標旁
- [ ] 組字中的文字有底線，按 Enter 或選字後只送出一次，不會多出換行
- [ ] 在 **粗體文字** 中間輸入中文，送出後仍是粗體
- [ ] 在標題、清單項目和表格儲存格裡各輸入一次中文
- [ ] 組字途中按 Backspace，只修改組字內容，不會刪掉前面的字
- [ ] 送出後按一次 Cmd/Ctrl+Z，整段剛輸入的字一起復原
- [ ] 從標題中間拖曳選取到清單，複製後貼到文件最後
